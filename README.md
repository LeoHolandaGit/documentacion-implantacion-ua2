# Documentación - Implantación de Aplicaciones Web (UA2)

## Finalidad del repositorio
Este repositorio privado tiene como objetivo organizar, documentar y mantener un control de versiones limpio de dos prácticas realizadas durante la Unidad de Aprendizaje 2, asegurando que toda la documentación publicada esté libre de datos personales o sensibles.

## Índice de documentos
1. **[Tarea 1: Despliegue seguro, pruebas y optimización (Pokédex)](docs/tarea1_Pokedex.pdf)**
2. **[Tarea 2: Despliegue y auditoría de seguridad (La Mesa Segura)](docs/tarea2_seguridad.pdf)**

## Descripción de los documentos
* **Tarea 1 (`docs/tarea1_Pokedex.pdf`):** Documentación del empaquetado de una versión candidata (`v1.0.0-rc1`), verificación de integridad mediante hash SHA-256, exclusión de archivos sensibles/temporales y comprobación del entorno XAMPP (Apache, PHP y MariaDB).
* **Tarea 2 (`docs/tarea2_seguridad.pdf`):** Guía de instalación en servidor local con MySQL (`restaurante_ua2`), control de acceso por roles (`admin` y `empleado`), pruebas de protección de rutas y preparación de un paquete limpio sin credenciales locales.

## Aprendizajes adquiridos
Con estas actividades he aprendido a preparar paquetes de software limpios antes de su distribución, verificar entornos de servidor en XAMPP, proteger rutas y archivos sensibles frente a accesos no autorizados y gestionar documentación técnica de forma ordenada en GitHub.
